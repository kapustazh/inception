Python / BM25 / Qwen / FastAPI

Local answers grounded in source code.

A retrieval-augmented generation system for the vLLM codebase. It indexes Python and Markdown, finds source passages with BM25, and uses Qwen3-0.6B for answers. Available through a CLI and local API.
